# Energy Nexus website

Static GitHub Pages site for the Energy Nexus trilogy by Kalamazoo.

## Publish with GitHub Pages

1. Create a public repository, for example `energy-nexus`.
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public site URL after deployment completes.

Edit `index.html` to update Book Two and Book Three, add Amazon links, or change author copy. Do not use placeholder ISBN or ASIN values.
